# عدسة — Photography Blog

React + Vite + Tailwind CSS photography blog built from the provided structure and JSON data.

## Run locally

1. Install Node.js (LTS).
2. Open a terminal in this folder.
3. Run:

```bash
npm install
npm run dev
```

4. Open the local URL shown by Vite.

## Production build

```bash
npm run build
npm run preview
```

## Included functionality

- Home page
- Blog page
- Search
- Category filtering
- Grid/List view
- Pagination (6 posts per page)
- Blog details routes
- 404 page
- About page
- Responsive RTL Arabic layout
- Font Awesome icons
- JSON data loaded from `public/data/posts.json`

## Important

`node_modules` is intentionally not included. It should be installed locally with `npm install`.

The blog image URLs are provided by the JSON data and require an internet connection when the site is running.
